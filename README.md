# Bread Store Landing Page

A simple responsive landing page for a sourdough bread store, built with React + TailwindCSS.

## Features
- Responsive design (mobile & desktop)
- Animated hero and about section
- Product gallery with hover effect
- Contact form + social media links

## How to Run
1. Clone the repo
2. Run `npm install`
3. Run `npm run dev`

## Tech Stack
- React
- TailwindCSS
- Framer Motion
- HeadlessUI
